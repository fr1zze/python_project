# Система учета заявок на командировки

## Назначение
Приложение предназначено для учета и обработки заявок сотрудников на командировки. Система позволяет создавать заявки на поездки, хранить информацию о командировках и сотрудниках, а также отслеживать процесс согласования заявок.

## Целевая аудитория
Система предназначена для сотрудников организаций, которые оформляют заявки на командировки, а также для руководителей, которые рассматривают и согласовывают данные заявки.

## Предметная область
Предметная область проекта связана с организацией служебных командировок сотрудников. Система хранит информацию о сотрудниках, планируемых поездках и заявках на командировки, а также позволяет контролировать этапы их согласования.

## Основные сущности
- сотрудник
- поездка
- заявка
- согласование

## Основные функции
- Проверка правильности дат поездки
- Расчёт продолжительности командировки
- Расчёт общей стоимости командировки
- Определение статуса согласования заявки

## План развития
На следующих этапах планируется:
- разработка веб-приложения;
- подключение базы данных;
- реализация пользователей;
- разработка API;
- контейнеризация приложения;
- настройка CI/CD.
