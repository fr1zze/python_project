# Система учёта заявок на командировки

Консольное приложение для учёта сотрудников, поездок и заявок на командировки. Программа позволяет создавать, одобрять и отклонять заявки.

## Возможности

- добавление и просмотр сотрудников;
- создание и просмотр заявок на командировки;
- поиск заявок по сотруднику и сортировка по дате поездки;
- проверка дат, расчёт продолжительности и стоимости поездки;
- согласование или отклонение заявки с проверкой бюджета;
- проверка пересечения одобренных поездок сотрудника;
- просмотр статистики по заявкам;
- сохранение сотрудников и заявок в JSON-файлах.

## Структура проекта

- `main.py` — запуск программы и консольное меню;
- `employees.py` — добавление и поиск сотрудников;
- `trips.py` — проверка дат и расчёт стоимости командировки;
- `travel_requests.py` — создание, поиск, сортировка и согласование заявок, статистика;
- `storage.py` — загрузка и сохранение JSON-файлов;
- `utils.py` — проверка ввода чисел и дат;
- `data/employees.json` — данные сотрудников;
- `data/requests.json` — данные заявок;
- `tests/test_project.py` — автоматические тесты;
- `requirements.txt` — инструменты для тестирования и проверки кода.

## Хранение данных

Сотрудники и заявки представлены списками словарей. В заявке содержатся идентификатор сотрудника, сведения о поездке, стоимость, лимит бюджета и статус согласования. Даты в JSON хранятся в формате `ГГГГ-ММ-ДД`, например `2026-10-01`. При вводе в меню используется формат `ДД.ММ.ГГГГ`.

## Требования

- Python 3.10 или новее;
- `pytest` для запуска тестов;
- `flake8` для проверки оформления кода.

Установить зависимости из папки проекта:

```powershell
py -m pip install -r requirements.txt
```

## Запуск программы

```powershell
py main.py
```

## Запуск тестов

```powershell
py -m pytest
```

## Проверка качества кода

```powershell
py -m flake8 .
```
